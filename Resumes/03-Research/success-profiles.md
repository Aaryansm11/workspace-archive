# Phase 3A — Role Success Profiles (market research, 2026)
**Generated:** 2026-06-06 · Method: skill `research-prompts.md` (role benchmarking via web research). India/remote, early-career.
> For each role: what the market screens for → Aaryan's fit → gaps → resume refinement. **Honest reality checks flagged.**

## Solutions / Sales Engineer
- **Market wants:** technical discovery, **demos / POC / proof-of-value**, solution design, translating tech↔business value, APIs/integrations, basic scripting (Python/SQL/API), **CRM (Salesforce/HubSpot)**, cross-functional w/ Product/Eng/CS. 2026: async/interactive demos, product-feedback loops.
- **Fit:** strong — HyperVerge = exactly this (solution design, integration, client-facing, HubSpot, Product/Eng feedback).
- **Refine:** add **discovery / demo / POC** + **CRM (HubSpot)** + "translate technical→business value" keywords.

## Technical Account Manager
- **Market wants:** account relationships, pre/post-sales technical support, troubleshooting, **upsell/cross-sell**, **QBRs/review meetings**, **performance-metrics reporting**, CRM, prioritization. (Typically 3–5 yrs; **junior TAM** exists.)
- **Fit:** good — 6 accounts, BI/stabilization, client comms. **Reality check:** most TAM roles want 1–3+ yrs; target **junior/associate TAM**.
- **Refine:** add metrics-reporting, review-cadence, upsell language; frame as new-grad/associate.

## Backend Engineer (Python/FastAPI)
- **Market wants:** Python 3.8+, FastAPI/Django/Flask, **async programming**, SQL (Postgres/MySQL) + NoSQL (Redis/Mongo), REST/HTTP, **Docker/CI-CD/cloud (AWS)**, **pytest**, service-oriented architecture.
- **Fit:** strong — SDIS/KGS (FastAPI, Postgres, JWT/RBAC), Redis, Docker/AWS.
- **Refine:** add **async**; add **pytest/CI** *after* we make SDIS CI real.

## Full-Stack Engineer
- **Market wants:** React, **Node.js**, **TypeScript**, Python, SQL+NoSQL, AWS, CI/CD, Git, API design, end-to-end ownership.
- **Fit:** partial. Has **React + 3D (R3F) + Python (FastAPI) + Supabase** (real, strong). **Reality check:** you **don't have Node.js or TypeScript** — the standard "React/Node/TS" JD is a stretch.
- **Refine:** ✅ **Removed Node/TS claims.** Position as **React + Python full-stack** (truthful, still competitive). Consider learning TS next.

## Data / Platform Engineer
- **Market wants:** **Kafka + Spark** (both = +30–50% value), SQL(79%)+Python(74%), **Airflow/orchestration**, warehouses (Databricks/Snowflake), cloud (Azure 75%, AWS/GCP), Scala/Java.
- **Fit:** partial-strong — **Kafka + Spark + Redis** (Emostream, real), big-data pipeline (capstone 1.3B pts). **Gaps:** Airflow/orchestration, warehouse, Scala — **not claimed.**
- **Refine:** lead with Kafka/Spark/streaming (real strength); honestly omit orchestration/warehouse.

## ML Engineer
- **Market wants:** Python, PyTorch/TensorFlow, **MLOps (Docker, Kubernetes, MLflow, CI/CD)**, **experiment tracking (MLflow/W&B/DVC)**, cloud ML (SageMaker/Vertex/Azure ML), SQL/Pandas/Spark, model monitoring. **57.7% prefer domain experts.**
- **Fit:** strong on modeling+deployment (PyTorch, LoRA, contrastive, FastAPI serving). **Gap:** MLOps (no MLflow/K8s/SageMaker) — **not claimed.** **Edge:** healthcare **domain expertise** (matches the "domain expert" preference).
- **Refine:** lean on deployment + **healthcare domain**; MLOps = clear next skill to build.

## AI / LLM (GenAI) Engineer  ⭐ best market fit
- **Market wants:** **RAG (35.9% of roles — #1)**, prompt engineering (29%), LLM knowledge (25%), **fine-tuning**, LLM APIs (OpenAI/Anthropic/Gemini), **LangChain**, vector DBs, Python, cloud, LLMOps/evals.
- **Fit:** **excellent** — LANGTRON (**LoRA fine-tuning**), SDIS (**RAG** + OpenAI/HF embeddings), KGS, FAISS, LangChain. Your real work maps to the **two most in-demand skills (RAG + fine-tuning).**
- **Refine:** emphasize RAG + fine-tuning + LLM APIs + vector DBs; this is likely your **strongest application track.**

## Applied Scientist / ML Research
- **Market wants:** strong math/stats, PyTorch/TF, **typically MS/PhD**, end-to-end ML at scale, applied research, experimentation, publications.
- **Fit:** publication (real edge!) + self-supervised/contrastive. **Reality check:** most "Applied Scientist" roles **require a graduate degree** — as a BS new-grad this is a stretch.
- **Refine:** retarget as **ML / Research Engineer** (attainable) and let the **IEEE paper** carry the research signal; keep "Applied Scientist" only for new-grad/research-associate programs.

## Healthcare / Biosignals ML
- **Market wants:** ML + **domain depth** (the 57.7% "domain expert" preference rewards this), clinical data, signal processing, regulatory awareness.
- **Fit:** **strong & differentiated** — publication + MIMIC-III + ECG/PPG + HIPAA (IGS). A genuine niche edge.
- **Refine:** keep as-is; it's one of your strongest, most defensible resumes.
